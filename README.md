# Echo News Center

Event-centric social news research prototype.

## Current delivery

A mobile-first GitHub Pages interface is being prepared. All bundled news, people, evidence and places in the demo are fictional. This is not a live news service or emergency information source.

The initial web release stores experimental posts and followed rooms only in the visitor's browser. It does not publish those posts to other people, run the P2.1 Python database on GitHub Pages, or automatically verify claims.

## Core principles

- One event room links original voices; it does not replace their authors.
- Evidence status and community discussion are separate.
- Popularity does not determine truth.
- Original sources, uncertainty and counter-evidence remain inspectable.
- A local draft excluded from aggregation must not appear in room views or counts.

## Deployment

The site uses relative asset paths and hash routing for the `/Echonews/` GitHub Pages project path. The repository will contain a static deployment workflow and reproducible frontend tests.
